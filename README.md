# Rent Calculator - Automated Expense Distribution System

## Project Overview

The Rent Calculator is a Python-based console application that was created to make sharing monthly household expenses easy and equitable. It calculates each roommate's share of rent, electricity, food, and other expenditures, saving time and reducing calculation errors.

## Features

* Calculates the total electricity bill with the units consumed and the rate per unit.

* Splits the rent and other expenses evenly among the roommates.

* Lets multiple calculations be performed in a session.

* Has a simple and user-friendly user interface made up of text.

* Helps avoid errors that could have been made when calculating manually.

## Motivation

Sharing expenses in a rented accommodation can lead to chaos and misunderstandings. This project provides an easy automated solution to dividing the common expenditure by providing a way to share the expenses easily and quickly.

## How to Use

1. Run the python file `rentcalculator.py`.
2. Enter the number of roommates when prompted.
3. Enter the rent, food expenses, electricity units, and rate per unit when prompted.
4. View the amount that each roommate needs to contribute.
5. Choose to perform another calculation or quit the application.
